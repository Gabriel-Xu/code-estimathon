A data deficient (DD) species is one which has been categorized by the International Union for Conservation of Nature as offering insufficient information for a proper assessment of conservation status to be made.

A data definition language or data description language (DDL) is a syntax similar to a computer programming language for defining data structures, especially database schemas.

A data dictionary, or metadata repository, as defined in the IBM Dictionary of Computing, is a "centralized repository of information about data such as meaning, relationships to other data, origin, usage, and format".

A data disk was also released for Populous II, titled Populous II: The Challenge Games.

A data element name is a name given to a data element in, for example, a data dictionary or metadata registry.

A data entry clerk is a member of staff employed to enter or update data into a computer system.

A data entry operator reentered the record and the keypunch compared the new keystrokes with those loaded into the buffer.

A data event is a relevant state transition defined in an event schema.

A data field is a place where you can store data.

A data flow diagram (DFD) is a graphical representation of the "flow" of data through an information system, modeling its process aspects.

A datagram is a basic transfer unit associated with a packet-switched network.

A data grid is an architecture or set of services that gives individuals or groups of users the ability to access, modify and transfer extremely large amounts of geographically distributed data for research purposes.

A data haven, like a corporate haven or tax haven, is a refuge for uninterrupted or unregulated data.

A data hazard can lead to a pipeline stall when the current operation has to wait for the results of an earlier operation which has not yet finished.

A data hub is a collection of data from multiple sources organized for distribution, sharing, and often subsetting and sharing.

A data infrastructure is a digital infrastructure promoting data sharing and consumption.

A data item describes an atomic state of a particular object concerning a specific property at a certain time point.

A data jam is a technically oriented workshop exercise where people solve problems using data sets.

A data janitor is a person who works to take big data and condense it into useful amounts of information.

A data lake is a system or repository of data stored in its natural format, usually object blobs or files.

A data lake is usually a single store of all enterprise data including raw copies of source system data and transformed data used for tasks such as reporting, visualization, analytics and machine learning.

A data library, data archive, or data repository is a collection of numeric and/or geospatial data sets for secondary use in research.

A data library may also maintain subscriptions to licensed data resources for its users to access.

A data logger (also datalogger or data recorder) is an electronic device that records data over time or in relation to location either with a built in instrument or sensor or via external instruments and sensors.

A data logger is commonly used to monitor shipments in a cold chain and to gather temperature data from diverse field conditions.
