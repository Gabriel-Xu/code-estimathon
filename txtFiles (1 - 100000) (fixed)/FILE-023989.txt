CMA CGM 22,000 TEU container ships refers to a group of nine container ships each with a capacity of 22,000 TEUs (twenty-foot equivalent unit) being built by the China State Shipbuilding Corporation (CSSC) for French shipping company CMA CGM.

CMA CGM Alexander von Humboldt is an Explorer class containership built for CMA CGM.

CMA CGM Amerigo Vespucci is an Explorer class containership built for CMA CGM.

CMA CGM Benjamin Franklin is an Explorer class containership built for CMA CGM.

CMA CGM Christophe Colomb is an Explorer-class container ship built for CMA CGM.

CMA CGM Fort Saint Louis is owned by the shipping company CMA CGM and sails under a French flag, with Marseilles as her home port.

CMA CGM had originally planned to name the ship after Benjamin Franklin.

CMA CGM Laperouse is an Explorer class containership built for CMA CGM.
