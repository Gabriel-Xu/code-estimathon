The OpenDocument Foundation, Inc. (not to be confused with The Document Foundation) was an organization set up in 2002 by Sam Hiser and Paul "Buck" Martin (real name Paul E. Merrell) to promote the use of open standards-based XML/RDF document formats for desktop computer use.The Open Document Management API is an API that simplifies the communication of desktop applications with document management systems (DMS).The Open Doek Film Festival, held annually in Turnhout, Belgium, since 1992, is an international film festival with a focus on world cinema.
